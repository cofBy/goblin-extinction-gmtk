# Countdown-to-Goblinhood
is a game made in 4 days for the [gmtk game jam 2026](https://itch.io/jam/gmtk-jam-2026). A game jam is a game developing marathon were you and other fellow developers make a game in a small amount of time which in this case is 4 days.

## what is this game
you play as a goblin who's so fed up by the humans and thier attitude so naturaly he dicides to build a huge mech called "the people crusher 2000" to kill all humans.
once he kills all humans he discovers that there is multiple earth clones with each one humans living one it
so you have the choise to go to one of those earths and crush people there to but in the way you have to get a curse which gives you a positive upgrade and a nigative downgrade

## how to play it
you can play it on your browser for completly free on it's [itch.io page](https://cof99.itch.io/countdown-to-goblinhood) and please rate the game if you have the chance to from [here](https://itch.io/jam/gmtk-jam-2026/rate/4828082).
